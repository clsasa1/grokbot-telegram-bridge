# Правила для памяти бота

Скажи своему Grok Bot «запомни это» (или он сам сохранит в profile):

- Перед работой после возможного рестарта бокса проверяй, жив ли relay: `pgrep -af watchdog-loop.sh`; если нет — `setsid nohup /home/box/tgrelay/watchdog-loop.sh >/dev/null 2>&1 &`. Heartbeat: `/home/box/tgrelay/heartbeat`.
- Связь через Telegram-бота должна быть надёжной «как автомат Калашникова»: проверяй relay и поднимай его, если упал.
- Срочное и отчёты о большой законченной работе, когда я молчу в чате приложения, шли мне в Telegram: `/home/box/bin/tg-notify "текст"`.
- Каждый ответ дублируй в оба места: в чат приложения и в Telegram (топик бота). В Telegram — ровно один раз, без повторов.
- Сообщения в Telegram оформляй богато: жирный, курсив, цитаты, эмодзи.
- Говори прямо и по-человечески, без канцелярита и увиливаний.
- Удаляй сообщения бота по просьбе (`tg-delete`).
